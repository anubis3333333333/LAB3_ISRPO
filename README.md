## Примеры возможностей разметки

### Текстовое форматирование и списки
В процессе работы были изучены:
1. **Полужирный текст** для выделения терминов.
2. *Курсив* для примечаний.
3. ~~Зачеркнутый текст~~ для устаревших подходов.
4. `Моноширинный текст` для обозначения команд внутри строк.

> Оформление документации — это лицо разработчика!
